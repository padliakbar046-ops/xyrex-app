Hubungkan sender WhatsApp ke XYREX

Pairing Code
Cara Scan QR (disarankan):
1. Klik Pairing Sekarang di bawah
2. QR muncul, langsung buka WhatsApp sender
3. Perangkat Tertaut → Tautkan Perangkat → Scan QR
4. Arahkan kamera ke QR di layar ini
5. Tunggu 2-3 detik, status jadi Sender Pribadi Aktif
Peringatan Pairing Code
Metode pairing code tidak selalu berhasil. Sering gagal karena:
  • Kode expired sebelum sempat diketik (valid ±60 detik)
  • Nomor sender bukan nomor WhatsApp aktif
  • Slot perangkat tertaut penuh (maks 4)
  • Kode diketik ke WA beda dengan nomor di input
  • WhatsApp tolak pairing dari perangkat tertentu
Disarankan pakai Scan QR.
Cara Pairing Code:
1. Isi nomor sender di bawah
2. Buka WhatsApp sender → Perangkat Tertaut → Tautkan dengan nomor telepon (siapkan dulu)
3. Baru klik Pairing Sekarang
4. Kode muncul → langsung ketik tanpa spasi dalam 20 detik
